# QuotaBar v0.4 — macOS Support (Spec Addendum)

**Date:** 2026-07-12
**Status:** User-approved. Windows keeps four bars (geometry tweak only);
macOS adds menu-bar text with a provider letter.

## Scope

Port QuotaBar to macOS (Apple-silicon first) as a menu bar app, verified on
GitHub Actions macOS runners (real Apple hardware: compile, full test suite,
Keychain functional test, launch + screenshot smoke, .dmg artifact). Final
on-device validation deferred until a physical Mac is available.

## 1. Windows tray geometry tweak (ships in the same release)

Four bars currently 6px wide / 2px gaps (total 30, margin 1). Change to
**7px bars / 1px gaps** (total 31, margins 1|0) so bars read less cramped at
16px. Icon tests updated to new x-ranges. No other Windows changes.

## 2. macOS menu bar icon + text

- Icon: same health-colored four bars as Windows (saturated health colors
  are legible on both light and dark menu bars). The monochrome/template
  variant from the design exploration is DEFERRED until real-device
  appearance testing.
- **Menu bar text (macOS only):** tray title set to `"{L} {N}%"` where L is
  the letter of the BINDING provider (lowest remaining among enabled
  providers) and N its remaining percent. Letters: `C`=Claude, `X`=Codex,
  `G`=Grok, `D`=DeepSeek. Binding provider unavailable → `{L} —`; all
  unavailable → `—`. Config `menubar_text: bool` (default true, ignored on
  Windows) turns the text off (icon-only).
- Title updates whenever the tray icon updates.

## 3. macOS platform branches

- **Claude credentials:** macOS Claude Code stores OAuth in the login
  Keychain (service `Claude Code-credentials`), not the plaintext file.
  `claude_token` on macOS: try the file first (some installs have it), then
  fall back to `security find-generic-password -s "Claude Code-credentials" -w`
  (stdout = the same JSON blob; parse with the existing logic). Keychain
  access isolated in a `#[cfg(target_os = "macos")]` helper; JSON parsing
  stays shared/tested. CI functional test: create a synthetic entry with
  `security add-generic-password`, read it through the helper, assert,
  delete it (macOS-only test, runs on the runner's unlocked keychain).
- **Panel position:** menu bar is at the TOP → panel anchors top-right
  (x = work right - width - 12, y = work top + 12), clamped to work origin.
  `panel_position` gains an anchor parameter (BottomRight = Windows,
  TopRight = macOS, chosen by cfg); pure function, tests for both anchors.
- **refresh_signin:** spawn via `/bin/zsh -lc "<fixed command>"` on macOS
  (GUI apps don't inherit shell PATH; -l loads login PATH). Fixed strings
  only, same claude/grok commands. `CREATE_NO_WINDOW` flag cfg(windows)-gated.
- Codex/Grok/DeepSeek credentials and all parsers: unchanged (same paths
  under $HOME).

## 4. CI: `mac.yml` workflow

Triggers: `workflow_dispatch` + tag push `v*` (NOT every push — macOS
runner minutes cost 10x). Jobs on `macos-latest` (arm64):
1. npm ci + build; `cargo test --workspace` (includes the Keychain test).
2. `npm run tauri build` → .app + .dmg.
3. Launch smoke: open the built .app, wait ~15 s, assert the process is
   alive, `screencapture` the screen, kill the app.
4. Upload artifacts: the .dmg and the screenshot (for remote visual review).

Windows CI workflow unchanged.

## Out of scope

Code signing / notarization (unsigned; first open = right-click → Open);
Intel (x86_64) build; monochrome template icon; App Store.
